Закоммить текущие изменения и запушь в `origin main`. Тема: $ARGUMENTS

Порядок:

1. `git status --short` и `git diff --stat` — покажи, что именно уходит.

2. **Проверка секретов перед коммитом.** В репозитории лежит `.env` с ключом OpenRouter и токеном
   Telegram-бота. Проверь, что он и другие чувствительные файлы не попали в индекс:

   ```
   git check-ignore -v .env agent.log crash.log memory_history.json profile.json
   ```

   Затем прогони содержимое индекса по шаблонам:

   ```
   git diff --cached | grep -nEi "sk-or-v1-[A-Za-z0-9]+|sk-[A-Za-z0-9]{32,}|[0-9]{8,10}:AA[A-Za-z0-9_-]{30,}"
   ```

   Нашлось совпадение — **останавливайся и спрашивай**, не коммить.

3. Отдельно убедись, что не уезжают личные данные пользователей и мусор: `data/`, `workspace/`
   (там лежат собранные PDF), `memory_history.json`, `profile.json`, `__pycache__/`, `node_modules/`.

4. Сообщение коммита: первая строка по-английски и по существу, тело по-русски — что изменилось и **почему**.
   Если чинится баг, опиши причину, а не только симптом.

5. Запушь и дай ссылку на коммит.

Не смешивай в одном коммите несвязанные вещи. Если изменений на две разные темы, предложи разделить.
